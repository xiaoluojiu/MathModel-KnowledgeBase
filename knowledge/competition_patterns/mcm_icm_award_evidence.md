# MCM/ICM Award Evidence Index

COMAP publishes official results and provides access to unabridged Outstanding Papers for recent MCM/ICM contests. The official 2025 and 2026 results pages identify Outstanding Winners by problem and award category, while the previous-contests index exposes problem/result archives back to 1999.

## Why this matters for the knowledge base

Award-winning solutions should be treated as **empirical case evidence** for relationships such as:

`problem pattern -> modeling strategy -> model family -> validation strategy`

They should not be converted into a rule such as `award-winning model = recommended model`.

## Source hierarchy

1. Official contest problem/data page.
2. Official contest results page.
3. Official organizer-hosted paper.
4. Secondary analysis with explicit provenance.

## Suggested mining procedure

For each selected paper, extract a compact case card rather than copying the paper:

1. Identify each subproblem.
2. Label its mathematical task.
3. Identify the data structure and observable patterns.
4. Record the model family and role.
5. Record why the paper's authors selected it when the paper provides evidence.
6. Record validation and sensitivity analysis.
7. Record alternatives or discarded models if discussed.
8. Link the case to the corresponding model cards.
