## 2026 update note

The official site currently lists the 2026 problem release and a 2026 commentary/experience-exchange notice. This registry should therefore be extended to 2026 A/B after source verification, while the original project milestone remains the 2010–2025 corpus.

## Paper corpus handling

The public 2010–2025 excellent-paper index points to a Baidu Netdisk collection. Because binary files from that host are not directly ingestible in the current GitHub connector, the repository must not claim full-PDF extraction unless each PDF has actually been retrieved and parsed. Public individual papers, official journal pages, university repositories and author-hosted copies can be used to progressively verify cases.
