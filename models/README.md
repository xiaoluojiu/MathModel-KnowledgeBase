# Core Model Catalog

The first model cards establish the canonical tagging and relation vocabulary. Each card is intended to be machine-readable first and human-readable second.

## Statistical / regression
- `linear-regression`
- `ridge`
- `lasso`
- `elastic-net`
- `logistic-regression`

## Machine learning
- `random-forest`
- `xgboost`
- `svm`
- `kmeans`
- `pca`

## Time series
- `arima`
- `sarimax`

The catalog will expand only after each model has a validated Model Card, applicability conditions, negative-match conditions, competition context, and model relations.
